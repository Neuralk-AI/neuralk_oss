# Security

## Supported versions

Only the latest release of `neuralk-oss` on [PyPI](https://pypi.org/project/neuralk-oss/)
receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub's private
vulnerability reporting: the repository's **Security** tab, then **Report a
vulnerability**, or directly
[github.com/Neuralk-AI/neuralk_oss/security/advisories/new](https://github.com/Neuralk-AI/neuralk_oss/security/advisories/new).

Include the version, what an attacker can do, and the steps or code to
reproduce it. We reply in the advisory, and publish it with the fix.
